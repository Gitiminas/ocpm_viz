# Online appendix

Material that accompanies the thesis but is not part of the tool: records made by looking at the
running application, kept beside the code so they can be checked against it.

| Folder | What it is |
|---|---|
| `visual-inventory/` | Every mark the tool can draw, as screenshots with notes (`INVENTORY.md`): sections A to I captured 2026-08-23, K (the Process page) and L (what changed since) on 2026-09-11 |
| `C6_ocel2.json` | An OCEL 2.0 export of one sub-log, as a sample of the format |
| `matview_dependency_graph_v3.html` | The upstream materialized views and what depends on what, as a page |

Nothing here is read by the application or by the tests. `docs/` holds the maintained record of
what the tool is; this folder holds what it looked like on a given day.
